# 📌 Bash
«В работе с удалёнными серверами без графического интерфейса я активно использую команды Bash. Этот опыт позволяет мне эффективно создавать, редактировать и удалять файлы и папки прямо из командной строки. Я рад поделиться командами, которые применял в ходе своего обучения и задач по тестированию (QA).»
## Задание 1

##### Выполнение домашнего задания
| 1 | `touch bash1.txt`                 # создаёт пустой файл `bash1.txt` |
| 2 | `cd ~/Desktop/bush_training`      # переходит в папку `bush_training` на Рабочем столе |
| 3 | `pwd`                             # показывает текущую папку |
| 4 | `mkdir test1`                     # создаёт папку `test1` |
| 5 | `cd test1`                        # переходит внутрь `test1` |
| 6 | `touch 1 2 3`                     # создаёт три файла: `1`, `2`, `3` |
| 7 | `ls`                              # показывает список файлов в папке |
| 8 | `cd ~/Desktop/bush_training`      # возвращается обратно в `bush_training` |
| 9 | `mkdir test2`                     # создаёт папку `test2` |
| 10 | `rmdir test2`                    # удаляет **пустую** папку `test2` |
| 11 | `rm test1/2`                           # удаляет файл `2` из папки `test1` |
| 12 | `mkdir test3 && cd test3 && touch 1 2` # создаёт папку `test3`, заходит в неё и создаёт файлы `1` и `2` |
| 13 | `cd .. && rm -r test3`                 # выходит на уровень выше и удаляет папку `test3` со всем содержимым |
| 14 | `mkdir test4`                    # создаёт папку `test4` |
| 15 | `mv test1/1 test1/3 test4/`      # перемещает файлы `1` и `3` из `test1` в `test4` |
| 16 | `cd test4 && echo "line1" >> 1 && echo "line2" >> 1 && echo "line3" >> 1` # заходит в `test4` и дописывает три строки в файл `1` |
| 17 | `cat 1`                          # показывает содержимое файла `1` |
| 18 | `echo "lineA" >> 3 && echo "lineB" >> 3 && echo "lineC" >> 3`      # дописывает три строки в файл `3` |
| 19 | `cat 1 3`                                                          # показывает содержимое файлов `1` и `3` |
| 20 | `nano 1`                                                           # открывает файл `1` в редакторе `nano` |
